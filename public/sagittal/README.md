# Midsagittal drawings

Drawings of the vocal tract for single sounds, by Richard Wright and Dan McCloy (University of
Washington Linguistics), from https://github.com/drammock/phonetics-teaching-assets
(`midsaggital_articulations`), under CC0 1.0 (see LICENSE). Unchanged; renamed to ASCII:
`ŋ.svg` → `ng.svg`, `s_laminal.svg` → `s.svg`.
