## 한국어 알아듣기 측정 (`tools/korean`, 2026-11-25)

엔진이 말한 한국어 106개 단어·문장(남/여 212개)을 Whisper small이 받아 적게 해서 비교. 기준값은
`tools/korean/baseline.json`. **단어 정답률 15.6%, 자모 오류율 61.3%** (남 57.2, 여 65.4).
문장은 잘 됨(감사합니다, 사랑해요, 괜찮아요, 미안해요 정답). 자주 틀리는 것: 예사소리가 거센소리로
(달→타르, 강→탕, ㄷ→ㅌ 10번), ㅅ→ㅆ, 받침 뒤에 모음이 붙음(말→마르, 물→무릎), ㄹ→ㄷ, ㅓ↔ㅏ, ㅜ→ㅗ/ㅡ,
ㅈ ㅉ ㅊ. 자세한 것과 실행법은 `tools/korean/README.md`. Whisper는 사람 귀가 아니라 참고값.

**문장 속 시험 (2026-11-26)**: 단어를 "다음 단어는 ___입니다"(붙여 씀)에 넣어 말하고 단어 부분만
채점(turbo, GPU로 4분). 처음 엔진 41.2% → 억양 폭 절반(0.95/1.07)+고른 모음 길이 **32.2%**. 원래
폭(0.9/1.15)은 받침 비음 위에 올림이 생겨 음절이 하나 더 들림(강→강의). 기준값
`tools/korean/baseline-carrier.json`. 같은 엔진도 채점마다 ±2 정도 흔들림.

### 한국어 억양 (2026-11-25)
단어 하나를 강세구로 보고 서울말 높낮이(Jun 2000: 첫소리가 ㅋㅌㅍㅊ ㄲㄸㅃㅉ ㅅㅆㅎ면 높게, 아니면
낮게 시작 → 둘째 음절 높음 → 끝 앞 낮음 → 끝 높음)를 붙임. 엔진 `Segment.tone`(말할 때 모음의 상대
높이, 한국어만 씀). 아직 사람 귀로 들어보지 않음. 높이 값(0.9/1.15)은 문헌 패턴에 맞춘 임시값.

## 작업 방식 메모

- Codex CLI 사용 가능: `codex exec -m gpt-6-astra --approve-for-me -C <폴더>`.
  `gpt-6.2-astra`는 이 계정(ChatGPT 로그인)에서 못 써요. 작업마다 git worktree를 따로 만들고,
  고칠 파일을 겹치지 않게 나눠요. 결과는 검토 후 합쳐요.
- Windows에서 `sed -i`로 고친 파일을 Vite가 못 알아채는 일이 있었어요. 화면이 이상하면 개발 서버 재시작.
- 말하기 계획의 시작 시간(`offset`)은 나중에 도착하고 알림이 없어요. `currentPlan()`을 그때그때 읽기.
- 공기 흐름처럼 짧은 순간은 화면 그리기가 아니라 `engine.onTelemetry`로 기록하기.
